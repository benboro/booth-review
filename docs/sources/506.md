# 506 Sports: page format

506sports.com publishes one college football TV schedule page per week, at
`https://506sports.com/ncaaf.php?yr=<season>&wk=<label>`. `<label>` runs `0`
through `16` for the regular season, plus `B` for one combined bowls/CFP
page. A season is exactly those 18 pages (docs/PLAN.md section 4.1).

506sports.com returns 403 Forbidden to booth-review's correctly-identified,
robots-respecting client. That block is never worked around (AGENTS.md); the
2025 season was saved by hand in a browser and imported with
`booth-review import 506`, and the 2014–2024 backfill (Phase 2) will need
the same manual path unless 506 allowlists the client first.

## Page layout

Each page groups its games under one heading per game date ("SATURDAY,
SEPTEMBER 27" — no year in the heading itself; the year comes from the
page's own `yr=` query and, on the bowls page, from watching the month
sequence roll from December into January). Under each date heading, one
listing block follows per televised game, holding four pieces of
information in a fixed order: the matchup, the kickoff time, the network,
and the announcing crew.

The bowls/CFP page prefixes each listing with a bowl or round name (for
example, "Frostbite Bowl" or "Frontier Bowl (CFP Quarterfinal)"), which
week pages don't have. One listing near the end of the bowls page names the
national championship before both participants are set (a location only,
no matchup yet); booth-review's parser drops a listing like that rather
than record a game with no teams.

## Fields

- **Matchup:** the away team, a separator, and the home team. Neutral-site
  games use " vs " ("Northfield State vs Lakeshore Tech"); a home game uses
  " @ " ("Northfield State @ Lakeshore Tech"). A neutral game's home side
  sometimes carries a trailing location note, kept as written (for example
  "Lakeshore Tech (in Example City)").

### Rank prefix

A ranked team's name is prefixed with its AP poll rank as a small
superscript-style number ("12 Northfield State @ Lakeshore Tech").
booth-review splits this into an integer field and leaves the team's own
name untouched. One rarer form pairs the AP rank with a parenthesized CFP
seed ("20 (11) Team A vs Team B" on the bowls page); only the AP rank
number becomes the structured field.

- **Kickoff time:** Eastern time, formatted like "7:30 PM". 506 is known to
  list some games as "TBA" before a kickoff window is set; booth-review
  treats a TBA or blank time as "unknown", not as any particular hour, while
  still recording the game's date.
- **Network:** the outlet name as 506 writes it (for example "ECN", or a
  comma-separated list like "ECN, ECN Digital" for a simulcast).

### Alt-cast and Spanish rows

A small share of listings mark an alternate broadcast of the same game
with an "(alt-cast)" suffix on the network text (for example "ECN
(alt-cast)"); none of 2025's 18 pages carried a Spanish-language
equivalent, though the format would presumably mark it the same way if one
appeared in another season.

### Crew delimiter

The announcers' names are comma-delimited ("Pat Example, Jordan Sample"),
sometimes three or four names for a bigger booth. A meaningful share of
listings — mostly smaller-audience and streaming-only games — list no
crew at all. Suffixes ("Jr.", "III") and period-style initials ("J. B.
Example") are kept exactly as written; booth-review's parser never merges
or edits a name.

## Conditional GET support

Unverified for 2025: the pages were hand-saved in a browser and imported,
not fetched live, so no live response headers were ever observed. The three
live requests booth-review did send (weeks 0–2, before the block was
recognized and the run stopped) also returned 403 without useful caching
headers. Whether 506 supports `ETag` or `Last-Modified` conditional
requests is an open question for whenever the site allowlists the client;
until then, every 506 fetch is treated as a one-time, never-repeated read
per page (AGENTS.md's no-re-fetch rule already assumes this).

## Quirks to watch in Phase 2/3

- The manual-import path (`booth-review import 506`) identifies a saved
  page by its own canonical link or title, not its filename, so a
  browser's default download name works as-is — but two different files
  claiming the same week are both rejected rather than guessed at.
- Older seasons' page layout is unverified; the parser was written and
  tested against 2025 only. The Phase 2 backfill should re-check a sample
  of older pages against this document before trusting the same parser
  unmodified.
- 506's own bowl-season page always spans a calendar year boundary; any
  code that assumes one page belongs to a single year needs the same
  December-to-January rollover booth-review's parser applies.
