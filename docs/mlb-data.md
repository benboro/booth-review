# MLB site data contract

`mlb-data.json` is the MLB site file (schema `1.0.0`). It is separate from
`site-data.json` (see `docs/site-data.md`) and `nfl-data.json` (see `docs/nfl-data.md`),
and the page loads it only when MLB is chosen, directly or through `?sport=mlb`, so a
college-football or NFL page load is unchanged. No CollegeFootballData.com field appears
in it.

The shapes are defined in `src/booth_review/contract/mlb_models.py`. The JSON Schema is
`docs/mlb-data.schema.json`, generated by `uv run python -m booth_review.contract.mlb_schema`
and pinned by a drift test (`tests/test_mlb_contract.py`). A synthetic example lives at
`tests/fixtures/contract/mlb-data.fixture.json`, produced by `tests/mlb_site_fixture.py`.

## Scope and rules

- **Three views, one file.** The Apple crews table (2026 regular season), the postseason
  booth grid (season by round) and the selection-driven games table with its detail
  panel. Only the games that feed those views ship, not every telecast.
- **Display fields only.** Small pre-aggregated data for the views. There is no
  downloadable bulk file of Retrosheet, Ratings Reference or any other source's data.
- **Analysis-only fields never ship:** `is_exclusive`, `production`, raw crew strings,
  the raw win-expectancy table, per-play series and Stats API payloads. `window` is
  allowed by the design but ships nowhere, since neither the Apple nor the postseason
  view needs it. Only values derived from them appear (adjusted figures and standard
  errors, the per-game excitement).
- **Strict models.** Every model forbids extra keys and does not coerce types. The
  validator reports `block.column[position]` only, never a cell value.
- **No wall-clock field.** Identical inputs give identical bytes. There is no
  `generated_at`.
- **Missing stays null.** A missing value is `null`, never 0.
- **Finite numbers only.** `NaN` and `Infinity` are not valid JSON, so the validator
  rejects them and the file is written with them disallowed.
- **Serialization.** Compact, key-sorted JSON, no trailing newline.

## Layout

Columnar like the NFL file: each block is an object of equal-length lists, and index
`i` across the lists is one row. Lookup columns hold indexes into `lookups`.

### freshness

`season`, `in_progress`, `retrosheet_through_season` (null until a Retrosheet season
is loaded) and `quality_pending`, true while any Apple booth is pending.

### constants

`excitement_method`, `stakes_method`, `low_n_threshold` and `coverage_bar` (the share
of games with a listed crew below which a postseason cell is flagged).

### lookups

`clubs` (id, name, league, division), `team_names` (club index, name, short, and the
season span the name applies to), `networks` (id, name, family), `people`, `players`
(Retrosheet ids and names, only players in shipped lineups), `rounds` (must equal
`regular, wild_card, division, lcs, world_series, tiebreak`), `leagues` (AL then NL) and
`eras` (a viewership era with its source link).

### games

`season`, `date`, `game_number`, `away`, `home` (club indexes), `round`,
`series_league`, `series_game`, `network`, `crew` (entries of person index and role
`pbp` or `analyst`), the crew credit (`crew_source`, `crew_source_url`, `press_url`,
`press_name`), `wp_excitement`, `stakes`, the viewership figure (`viewers`,
`viewership_label`, `scope`, `era`, `rr_url`, `source_url`), `cause`, and the lineup
pointer (`lineup_status`, `lineup_start`, `lineup_end`).

- `round` is one of the `rounds` names; a regular-season game has no `series_*` values
  and a World Series game has no `series_league`.
- `crew_source` is `override`, `506`, `relay`, `wikipedia` or null. It is set exactly
  when `crew` is non-empty ("crew not listed" is an empty crew). A `relay` crew needs an
  https `crew_source_url`, an https `press_url` and a `press_name`; a `wikipedia` crew
  needs the article URL as `crew_source_url`; `press_*` is null otherwise.
- A `viewers` value (greater than zero) needs https `rr_url` and `source_url`, a `scope`
  and an `era`, and a null `cause`. A null `viewers` needs a `cause`: `pending`, `none`,
  `regional`, `per_network` (a figure shared across networks is reported, not split),
  `ambiguous_doubleheader`, `conflict` or `window_level`.
- `lineup_status` is `present`, `pending` (waiting for Retrosheet 2026) or `missing`
  (not in Retrosheet). `lineup_start` and `lineup_end` are an inclusive row range in
  `lineups` and are set only for `present`.

### lineups

Flat rows: `game`, `side` (`away` or `home`), `slot` (0 is the starting pitcher, 1 to 9
the batting order), `player`, `position` and `starter_uncertain`. A game's rows are the
contiguous range its `lineup_start`/`lineup_end` name.

### apple_booths and apple_summary

One row per Apple booth: `rank_label`, `pbp`, `analyst`, `games`, `crew_listed`,
`relay_crews`, raw and adjusted stakes (stakes lead, excitement second), `raw_stakes_n`,
standard errors, `strength_prior`, `low_n`, `quality_status` and `game_list`.
`quality_status` is `pending` until Retrosheet 2026 is loaded, and while pending every
stakes and excitement figure is null and the views show "pending Retrosheet 2026".
`apple_summary` holds the lead-minus-others differences with standard errors (null while
pending), the lead and others counts, `rr_rated` and `apple_games`.

### postseason and postseason_seasons

`postseason` has one row per season, round, league and network: the booths (each a
`[pbp, analyst]` person-index pair), games, crew-listed count, coverage numerator and
denominator, mean excitement with its n, mean viewers with its n, and `game_list`. A
cell below `constants.coverage_bar` is flagged; a game with no crew reads "crew not
listed". `postseason_seasons` carries each season's coverage numerator and denominator,
which must equal the sum over its cells.

## Credits

Every displayed crew and figure carries its credit.

- **Retrosheet.** Shown wherever Retrosheet-derived stakes, excitement or lineups
  appear, in these exact words:
  "The information used here was obtained free of charge from and is copyrighted by Retrosheet."
  and "Interested parties may contact Retrosheet at www.retrosheet.org".
- **Ratings Reference.** Each viewership figure keeps its Ratings Reference record URL
  (`rr_url`) and the figure's original `source_url`, with a note that we changed the data.
- **Wikipedia.** Round, league, outlet and list-derived crews are from Wikipedia text
  under CC BY-SA 4.0, credited with the article URL (`crew_source_url`).
- **506 Sports.** 506-sourced crews, networks and windows link to the saved league page
  (`crew_source_url`). 506 Sports' data comes down if its owners object.
- **Relay.** A relay crew links the blog post (`crew_source_url`) and the press page it
  cites (`press_url`, `press_name`).
- **Overrides.** A hand-confirmed override wins over every other crew source.

## Versioning

`schema_version` is `1.0.0`. A change to the shape bumps the version and regenerates
`docs/mlb-data.schema.json`.
