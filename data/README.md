# Data

Everything in this folder is gitignored except this README and `reference/`. The
data comes from third-party sites, and being publicly viewable doesn't make it ours
to redistribute. A table is committed only when every source it draws on allows
republishing (see [Sources](#sources)).

| Folder | Contents | Committed? |
|---|---|---|
| `vault/` | A clone of the private data repo: `raw/` (pages and API responses, cached so each is fetched only once), `interim/`, `processed/`, `ledger/` (`frozen.json` records which season × source is frozen; `rr_lastmod.jsonl`, an append-only log read together with the older, no-longer-written `rr_lastmod.json` snapshot, tracks each Ratings Reference record's last-seen sitemap `<lastmod>`, used by `refresh ratingsref`; `job_state.json` records the scheduled job's last successful run, for catch-up; plus the CFBD and request call ledgers), `raw/nfl/` (NFL sources, kept apart from the college-football files; `ledger/nfl_nflverse_assets.jsonl` tracks changes to nflverse release assets), `raw/smw/<season>/` (hand-saved Sports Media Watch season pages, chart images and their transcriptions), `raw/tvrg/` and `raw/aa/` (The TV Ratings Guide and Awful Announcing index pages and ratings posts, cached by `booth-review collect tvrg|aa`; `ledger/policy_checks.jsonl` logs each site's robots.txt and terms re-check; `ledger/aa_feed_watch.json` holds the Awful Announcing feed's ETag / Last-Modified, the verified feed URL, and each 2026 week's schedule-post link or plain-reminder mark, never post text), `raw/espnpr/<season>/` (hand-saved ESPN Press Room commentators pages, weekly releases and ratings releases), `raw/mlb/` (MLB sources: `sports506`, `ratingsref`, `retrosheet`, `wikipedia` and `relay`; `statsapi` only if the user approves its single test request), `audit/` (completeness reports and the freeze sign-off baseline), `spike/`. Vault `interim/` and `processed/` copies are rebuilt from `raw/` on every run and never read back as state | Never (not even here — it's a separate private repo) |
| `incoming/506/cfb/`, `incoming/506/nfl/` | Hand-saved 506 Sports week pages for each league, waiting for `booth-review import 506` | Never |
| `incoming/506/mlb/` | Hand-saved 506 Sports MLB week pages (2026) and postseason round pages (2025-2026), waiting for `booth-review import 506 --league mlb` | Never |
| `incoming/mlb-relay/` | Staging CSV of 2026 MLB crews transcribed in a Claude Code session from the fan schedule blog, waiting for `booth-review import relay` | Never |
| `incoming/smw/<season>/` | Hand-saved Sports Media Watch season pages and chart images, with their session transcriptions, waiting for `booth-review import smw` | Never |
| `incoming/espnpr/` | Hand-saved ESPN Press Room pages (any filename), waiting for `booth-review import espnpr` | Never |
| `incoming/lineups/<family>/` (disney, fox, cbs, nbc) | Hand-saved network lineup pages for Phase 10 booth tiers; no booth-review command reads them. A Claude session reads the pages and proposes rows for `data/reference/cfb_booth_ranks.csv`, which the user confirms row by row; only the facts and the `source_url` reach `data/reference/` | Never |
| `processed/` | Joined tables that feed the plot and the models, published from this public repo | Only tables whose sources all allow it. Publish one by adding a `!data/processed/<file>` line to `.gitignore`, after `!data/processed/` and `data/processed/*` |
| `reference/` | Hand-maintained tables (`nfl_booth_ranks.csv` holds facts and the URL from network lineup releases, never the page): team-name crosswalk, announcer name variants, event flags, per-network `network_rarity.csv` (hand-set rarely-rated flag) | Yes |

## Sources

| Source | Terms | Can we republish derived data? |
|---|---|---|
| [Ratings Reference](https://ratingsreference.com/methodology) | Its compilation and JSON records are [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The figures themselves are facts credited to their original publishers | Yes. Credit RatingsReference.com, link each record used, cite each figure's original source, and note that we changed the data |
| [CollegeFootballData.com](https://collegefootballdata.com) | Its [terms](https://collegefootballdata.com/terms), updated August 12, 2026, permit using API data in websites, reasonable portions of factual data inside a larger product, and derived outputs such as charts; they prohibit providing API data as a standalone dataset or bulk download, mirrors, substitute APIs, and exposing keys in public code. Attribution ("Data provided by CollegeFootballData.com") is appreciated, not required | Yes, in the interactive chart. CFBD's admin confirmed by email on September 25, 2026 that its fields, including `excitementIndex`, may be used in the chart. A downloadable file may contain our own analysis and ordinary exports, but never a bulk download of CFBD's fields, even reformatted. Credit "Data provided by [CollegeFootballData.com](https://collegefootballdata.com)" on the site |
| [506 Sports](https://506sports.com/ncaaf.php) | No robots.txt, and no terms or copyright notice on its schedule pages. Blocks automated clients (403 Forbidden, confirmed 2026-09-25); its pages are saved by hand in a browser and brought in with `booth-review import 506` | Crews and networks are shown, credited to 506 Sports with a link. The owners were asked and have not replied; if they object, these come off the site |
| [nflverse](https://github.com/nflverse/nflverse-data) | The data is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); credit nflverse. Betting-line (`spread_line`) columns and play-by-play carry no stated provenance, so they are analysis-only (see `docs/sources/nfl-field-list.md`) | Derived values only, with credit to nflverse. Never the odds columns or play-by-play themselves |
| [Wikipedia](https://en.wikipedia.org) | Article text is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | Only extracted scheduling facts, with the article URL; derived data that includes them is share-alike |
| [506 Sports NFL](https://506sports.com/nfl.php) | Same as the college-football row: no terms or copyright notice; pages are saved by hand | Crews and networks are shown, credited to 506 Sports with a link. The owners were asked and have not replied; if they object, these come off the site |
| [Sports Media Watch](https://www.sportsmediawatch.com/college-football-tv-ratings/) | No terms page; the footer carries a copyright notice. Its robots.txt blocks scripts, so nothing is fetched: season ratings pages are saved by hand in a browser, their chart images are transcribed in Claude Code sessions (two independent passes, no OCR script), and `booth-review import smw` brings them into the vault | 2021–2024 per-game viewer figures are shown, credited to Sports Media Watch with a link to the season page. The transcriptions stay in the private vault and are never published. If Sports Media Watch objects, its figures come off the site |
| [The TV Ratings Guide](https://www.thetvratingsguide.com) | No terms page; the footer carries a copyright notice. Its robots.txt allows every path and sets no Crawl-delay (re-checked 2026-10-13). `booth-review collect tvrg` reads its archive pages and daily ratings posts, only for 2021–2024 dates that still have an unrated game on ABC, CBS, NBC, FOX, ESPN, ESPN2 or FS1, and only after a robots.txt and terms re-check from the last 30 days | 2021–2024 per-game viewer figures are shown, credited to The TV Ratings Guide with a link to the exact post. The cached posts stay in the private vault. If it objects, delete `raw/tvrg/` from the vault and rebuild, and its figures come off the site |
| [Awful Announcing](https://awfulannouncing.com) | Its disclaimer has no clause on automated access; its robots.txt disallows only a few old archive-index paths and sets no Crawl-delay (re-checked 2026-10-13). `booth-review collect aa` reads its sitemaps and college football ratings posts on the same gap-only terms and re-check as The TV Ratings Guide. In 2026 the scheduled job also reads its schedules feed on Tuesday evenings for the weekly college football announcing-schedule post's link only (Phase 25). For the 2026 season only, `booth-review collect aa --crews` fetches the schedule posts the feed watch recorded and caches each under `raw/aa/crews/2026/wk-NN.html` in the private vault; the derived crews are credited per post and never published as a table | 2021–2024 per-game viewer figures can be shown, credited to Awful Announcing with a link to the exact post; none is a headline yet. The cached posts stay in the private vault. If it objects, delete `raw/aa/` from the vault and rebuild, and its figures come off the site |
| [ESPN Press Room](https://espnpressroom.com) | The Disney Terms of Use ban automated access, so nothing is fetched: commentators pages and weekly and ratings releases are saved by hand in a browser and brought in with `booth-review import espnpr`, which identifies each page by its canonical link and body class. The scheduled job lists the current week's commentators page when it is not saved, and never fetches it | Backup crews for ESPN-family games with no hand-confirmed override and no 506 crew, and 2021–2024 per-game viewer figures ranked last; each is credited to ESPN Press Room with a link to the exact page, and none is shown yet. The saved pages stay in the private vault. If ESPN objects, delete `raw/espnpr/` from the vault and rebuild, and its crews and figures come off the site |
| [Retrosheet](https://www.retrosheet.org) | Open attribution: any use is allowed with a prominent credit. `booth-review collect retrosheet` reads only the game info file, the per-season plays files and the `allplayers` file under `/downloads/`, never `/gamelogs/` or `/boxesetc/` (its robots.txt disallows them) | Yes, with the exact credit line on every page that shows Retrosheet-derived data: "The information used here was obtained free of charge from and is copyrighted by Retrosheet. Interested parties may contact Retrosheet at www.retrosheet.org" |
| [Wikipedia (MLB)](https://en.wikipedia.org) | The '<year> Major League Baseball postseason' articles from 2014 and the named broadcaster list pages, read with `booth-review collect wikipedia --league mlb`. Text is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | Only extracted facts (rounds, series, outlets, lead-booth markers) with the article URL; derived data that includes them is share-alike |
| [506 Sports MLB](https://506sports.com) | Same as the college-football row: no terms or copyright notice; pages are saved by hand and brought in with `booth-review import 506 --league mlb`. 506 has no MLB round pages before 2025 | Networks and crews are shown, credited to 506 Sports with a link, following the college-football display precedent. 506's owners cannot be reached, so the stated path is takedown: if 506 objects, these come off the site |
| Fan schedule blog (`tamirmoore.blogspot.com`) | Secondary crew source for 2026 MLB games 506 lists without a crew. It states no terms; each list credits the network press page it copied. The user waived the terms question for analysis and display. A Claude Code session reads it once (2026) under the exception in `AGENTS.md`; it is never a `collect` source | Each relayed crew may be shown, credited to the blog post and the press page it cites. The extracted facts stay in the private vault (`raw/mlb/relay/`), never in this repo. If the blog or a press publisher objects, its crews come off the site |
| [MLB Stats API](https://statsapi.mlb.com) | MLB's data notice permits only individual, non-commercial, non-bulk use. The user waived the terms question for analysis; presentation is acceptable and bulk use is not. `booth-review collect statsapi` stays disabled until the user approves one test request, and serves capped 2026 lineup requests only if approved; otherwise it is unused (see `docs/sources/mlb-statsapi.md`) | Analysis only; no bulk or standalone dataset. Nothing from it is published as a table |
